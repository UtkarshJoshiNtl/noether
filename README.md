`noether` is a work-in-progress orbital propagation testbed; what exists materially today is a Kepler two-body force model with J2–J4 perturbations in km and km/s, and a small set of fixed-step integrators (Verlet, RK4, Yoshida4). The old paper framing is retired, and the repo is being reset toward a precision-aware testbed for long-term orbital propagation, starting from this minimal, reproducible core; everything beyond it is provisional and subject to change.
